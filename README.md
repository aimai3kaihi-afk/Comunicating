# ひとことメモ

ログイン不要の、日本語チャット＋共有メモ帳です。

- `/` で部屋の名前を入力 → `/r/部屋名` に入れる（同じ名前なら誰でも同じ部屋）
- 「内緒の部屋」ボタンでランダムな部屋名（推測されにくいURL）を作成
- チャット：名前（ニックネーム）だけで発言、リアルタイム更新、URLは自動リンク
- 共有メモ：入力すると約0.5秒後に自動保存され、部屋の全員に反映
- 日本語入力の変換確定のEnterでは送信されません（Shift+Enterで改行）

## 動かし方

```
node server.js
```

→ http://localhost:3000 （Node.js 18以上。インストールするパッケージはありません）

## 公開するには

Node.jsが動いて、ディスクにデータを保存できるサービスならどこでも動きます（Render / Railway / Fly.io / VPSなど）。

- 起動コマンド：`npm start`
- 環境変数 `PORT`（多くのサービスが自動設定）
- データ保存先は `DATA_DIR`（初期値は `./data`）。無料プランなどでディスクが永続化されない場合、再デプロイで部屋のデータが消えます。永続ディスクを `DATA_DIR` にマウントしてください。

## 仕様・制限（server.js の先頭で変更できます）

- 部屋ごとに最新500件まで保持 / 1発言1000文字 / メモ20000文字
- 30日更新のない部屋は自動削除
- 書き込みはIPごとに1分30回まで

## 注意

認証がないので、URLを知っている人は誰でも読み書きできます。個人情報やパスワードは書かない前提で使ってください。荒らし対策が必要になったら、部屋ごとの合言葉やメッセージ削除機能を足すのが次の一歩です。
